# Transit rooms sample

A room library with transition rooms, and a run of three levels chained
by their map names: the transit sibling of `samples/rooms-3x3` (the rooms
design, sections 11 and 15.7). It is kept apart so the 3x3 library stays
without roles and its levels and digests do not change.

Everything in this folder except this README is generated by
`SourceSharp.MapGen.Rooms.RoomsTransitSample` and checked by a test to be
exactly what the generator writes. Do not edit the files by hand; change
the generator and regenerate with `tools/RoomsSample --transit
samples/rooms-transit`.

## What is here

| Path | What |
| --- | --- |
| `gameinfo.txt` | A game that mounts only this folder, so the sample compiles with no Steam install. |
| `materials/rooms3x3/*.vmt` | The 3x3 kit's materials and a trigger material. |
| `rooms.vmf` | The library: the 3x3 kit's five kinds, then `lift_up` and `lift_down`, in a line. |
| `levels/transit_01.yaml` ... `transit_03.yaml` | The run, exactly as `ssmap layout` writes it (below). |

### The rooms

| Room | Role | What it holds |
| --- | --- | --- |
| `cross`, `tee`, `corner`, `hall`, `end` | none | The 3x3 kit's rooms, each with a `spawn` point of interest; `end` keeps its `info_player_start`. |
| `lift_up` | up | Four doors; a `func_button` whose `OnPressed` fires `Transition` at `cxry_transition`; the transition volume (`trigger_room_transition` named `cxry_transition`); an arrival facing east and two spawn points. |
| `lift_down` | down | Four doors; a `trigger_once` hallway whose only output fires `Transition` at the volume inside it; an arrival facing north. |

A room's role is the `room_role` key on its `info_room`. Points of interest
are `info_poi` entities with `poi_type` `arrival` or `spawn`; they are
compiled into the navigation and never reach a map.

### The levels

```sh
ssmap layout rooms.vmf -rows 3 -columns 3 -seed 1 -transition-distance 2 \
    -sequence 3 -name transit -out levels
```

writes `transit_01` (the top: `up: none`, `down_map: transit_02`),
`transit_02` (`up_map: transit_01`, `down_map: transit_03`) and
`transit_03` (the bottom: `down: none`, `up_map: transit_02`), from seeds
1, 2 and 3, with each level's up and down rooms at least two doors apart.

## Building it

```sh
ssmap room rooms.vmf -game .
ssmap link levels/transit_02.yaml                    # stock entities
ssmap link levels/transit_02.yaml -mod-entities      # the mod's logic_level_transition
ssmap link levels/transit_02.yaml --flatten          # the same level as one VMF
```

Without `-mod-entities` each transition room becomes a `trigger_changelevel`
and an `info_landmark` (the down room's hallway folded into the
changelevel), and the level spawns at the up room's arrival and spawn
points with one `info_player_start` each; the rooms' own player starts are
stripped. With it, each volume becomes a `logic_level_transition` and the
mod reads the arrival and spawn points from the `.nav3d` sidecar.
